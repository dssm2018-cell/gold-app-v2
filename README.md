# Gold App V2 — Database-first foundation

## الأساس المعتمد
هذه النسخة مبنية مباشرة من `V6-2-Fix1(3)` بدون إعادة بناء من الصفر. النسخة الأصلية محفوظة كاملة داخل `legacy/`.

## الهدف
- Cloudflare Pages للواجهة والاستضافة.
- Supabase لقاعدة البيانات والمصادقة.
- لوحة إدارة منفصلة.
- واجهة العميل تعرض الاختبار والنتيجة والتفاوض فقط.
- تغييرات الإدارة تحفظ في قاعدة البيانات وتُحمّل للواجهة.
- دعم الثيمات.
- وضع تجريبي يعمل محليًا قبل إضافة بيانات Supabase.

## التشغيل
1. ارفع محتويات هذا المجلد إلى Cloudflare Pages.
2. انسخ `config/app-config.js.example` إلى `config/app-config.js` وضع رابط Supabase وAnon Key.
3. نفّذ `database/schema.sql` مرة واحدة داخل Supabase SQL Editor.
4. أنشئ مستخدم المدير من Supabase Auth.
5. افتح `/admin/` لإدارة الإعدادات.
6. افتح `/client/` لواجهة العميل.

## ملاحظة مهمة
هذه هي مرحلة «الجسر» الأولى: نحافظ على منطق V6 الأصلي كما هو، ونفصل قاعدة البيانات واللوحة عن الواجهة. لا نعيد كتابة الحسابات الحالية الآن. بعد نجاح الربط، ننقل الأقسام واحدًا واحدًا إلى جداول منظمة.
